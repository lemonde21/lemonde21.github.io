# lemonde21.github.io

My portfolio site, served by GitHub Pages at **https://lemonde21.github.io**.

Plain HTML, CSS and a little JavaScript: no build step. Edit `index.html`, push to `main`, and GitHub Pages updates the site within a minute or two.

- `index.html`: content
- `style.css`: the dark Aero theme (glass windows, glossy controls, dusk backdrop)
- `script.js`: syntax colouring for the code excerpts, tabs, the Settings/terminal preview, and the taskbar clock
